FAQ

Questions judges ask.

MOST ASKEDWhat if the AI remembers something wrong?

Three guards stop bad memory from spreading.

1. Strict checks on model output. Every record is validated before it is saved. Unknown fields are dropped, types and statuses must match a fixed list, and file paths must stay inside the repo.

2. Proof before "done". A task can only be marked done, or an error marked verified, if a passing command result backs it. Without that, MEMO downgrades the claim and flags it.

3. You can delete anything. memo clear --record <id> removes one record, --session removes a whole session, and a tombstone stops it from being re-imported. Everything is plain Markdown and JSONL you can read and edit.

Does my code leave my machine?

File contents never do. Each API call sends the repo folder name, up to 60 open records and one redacted batch of session events, capped at 12,000 tokens. Keys, .env files, .pem and .key files are stripped before anything is written. Set the provider to mock and no network call happens at all.

How is this different from CLAUDE.md?

CLAUDE.md is a file you write and keep updated by hand. MEMO writes and updates its memory on its own from what actually happened in your sessions, tracks status (open, fixed, done) with evidence, and keeps it in your repo so teammates get it too.

What does it cost to run?

Groq is the default and has a free tier. MEMO has a default monthly budget cap of $5 and an optional daily token cap. The Scout agent's first run cost $0.00021 for 4 issues.

Does it work on Mac and Linux?

Yes. Capture, extraction and recall work everywhere with Node 20+. Windows gets the scheduled task set up automatically; on Mac and Linux you add one cron line that runs memo cycle.

Will the Worker agent push code without me?

No. The Worker only opens a draft pull request, and only when the test suite passes. Merging is always your decision.

Get started

Three steps. Then just code.

Needs Node 20+ and Git.

  1. Download

    Clone and install once. On Windows, setup_memo.bat also registers the background task.

    git clone https://github.com/sunil5151/Whisper_Flow_v1node bin/memo.js install

  2. Activate a repo

    Turn MEMO on inside your project and add a model key.

    memo initmemo key set

  3. Code as usual
